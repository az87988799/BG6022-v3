## Scope

M3 adds two architecture extensions:

1. The registered `b3lyp_d3bj_def2svp` method profile for gas-phase SP, Opt,
   and Freq through the existing ORCA Tool chain. It is limited to H/C/N/O,
   declares ORCA 6.1.1 as its validated version, and exposes no automatic
   scientific repair actions in this candidate.
2. The independent `geometry_distance` Tool. It consumes a verified
   `molecular_geometry` Artifact and strict, distinct 1-based `atom_i` and
   `atom_j` values, returns `interatomic_distance` in angstrom, and does not
   consume ORCA compute budget or permission.

The request and planner contracts are metadata-driven: operation-free result
requests are supported, request parameters are projected only to declared Tool
consumers, and an Opt-to-distance geometry source can be selected by Tool name.
`Agent.advance()` received no B3LYP- or distance-specific scheduling branch.

## Acceptance boundary

The candidate demonstrates the implementation and the available real ORCA
evidence. It does not claim that the B3LYP profile is scientifically validated
for all molecules, elements, environments, ORCA versions, or repair strategies.
The LLM matrix and the r2SCAN-3c failure-repair-to-distance live path remain
explicitly unexecuted in this environment. After review, the user may request
corrections or accept M3; only an explicit acceptance may change this status to
accepted.
