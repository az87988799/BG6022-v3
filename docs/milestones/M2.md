**Status:** implementation and validation are complete for review; **awaiting

## Goal and scope

M2 composes the existing molecule and ORCA Tools for explicit Opt, Freq, and SP
requests. It adds the frequency Tool, safe reuse of successful historical
geometries in new Runs, and program-verified scientific checks that gate
dependent Steps. One Agent loop and one ORCA input/runner/parser/check path remain
the execution boundary.

The candidate demonstrates Opt-only, SP-only, Opt/Freq, and Opt/Freq/independent
SP behavior. Plans declare Tools, input references, requested results, and check
dependencies; no fixed Opt/Freq/SP protocol was added. Frequency completion is
kept separate from local-minimum support.

## Boundaries and acceptance

- Runtime objects remain `Request`, `Plan`, `Step`, `Tool`, `Run`, `Result`, and
  `Artifact`.
- A `Tool` remains the execution boundary; a Plan composes Steps and does not
  encode a fixed protocol.
- Fakes are test-only; real ORCA and simulated evidence remain separate.
- The master plan lists 2048 MB / `%maxcore 384`; the current user-provided
  project instructions require 1024 MB / `%maxcore 192`. This implementation
  follows the current project instruction and records the difference rather
  than silently changing the active budget.
