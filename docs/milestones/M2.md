## Goal and scope

M2 composes the existing molecule and ORCA Tools for explicit Opt, Freq, and SP
requests. It adds the frequency Tool, safe reuse of successful historical
geometries in new Runs, and program-verified scientific checks that gate
dependent Steps. One Agent loop and one ORCA input/runner/parser/check path remain
the execution boundary.

The candidate demonstrates Opt-only, SP-only, Opt/Freq, and Opt/Freq/independent
SP behavior. Plans declare Tools, input references, requested results, and check
dependencies; no fixed Opt/Freq/SP protocol was added. Frequency completion is
kept separate from local-minimum support.

## Root-cause repair candidate (2026-09-16)

The following fixes close the four reproducible gaps recorded in the repair
plan:

- Intake and Planner share a result-target catalog generated from the live Tool
  registry. Canonical result names and finite legacy aliases resolve to the
  same targets, ambiguous Opt/SP energy requests are rejected, and downstream
  geometry bindings preserve the user's explicit source.
- Empty structured LLM responses use the existing bounded correction budget.
  Intake and Planner failures are reported by stage, with bounded diagnostics
  retained without credentials or response bodies.
- Request parameters are scoped to the Tools that consume them. Unsupported
  values are rejected before Run creation, confirmation-time edits validate
  atomically, and preparation failures leave a terminal Run state.
- Historical-geometry clarification only intercepts chemistry-compute intent;
  history questions continue through the result-query path.

The post-fix offline suite passed **224 tests, with 3 skipped**. Ruff lint,
format checking, Python compilation, and `git diff --check` also passed. Fresh
live Agent/ORCA entry paths have not yet been rerun against this repair
candidate; the real Runs below are retained as pre-fix baseline evidence and do
not certify the new natural-language routing or correction behavior.
