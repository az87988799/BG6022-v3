# M0 milestone handoff

M0 supplies the execution boundary that M1 will call:

```text
Request -> Plan -> Step -> Tool.execute
        -> deterministic ORCA input
        -> controlled process
        -> evidence-first parser/checks
        -> Result / Artifact / Run JSON
```

Implemented tools are `single_point` and `optimize_geometry`. M0 intentionally
does not add natural-language planning, PubChem/RDKit, frequency analysis, or
automatic repair. A failed optimization may publish a `restart_candidate`; only
a later, validated M1 repair path may consume it.

The final minimal-fix implementation and local execution evidence are recorded
in `docs/acceptance.md` and `docs/evidence/M0-repair-evidence.md`. The stage
was accepted by the user on 2026-09-11 after review of the pushed implementation
and evidence package.
